# Итоговый отчёт по интеграционному тестированию eShopOnWeb

## 1. Цель

Проверить основные пользовательские и интеграционные сценарии eShopOnWeb как единой системы и подготовить набор тестовых артефактов для портфолио.

## 2. Объект тестирования

Microsoft eShopOnWeb — ASP.NET Core reference application.

Проверяемые области:

- Web UI;
- Catalog;
- Basket;
- Checkout;
- Identity/Auth;
- Orders;
- Admin UI;
- PublicApi;
- test environment.

## 3. Подход

Использован подход Big Bang Integration Testing: приложение рассматривается как единая собранная система, а проверка выполняется через сквозные пользовательские сценарии.

## 5. Результаты

В рамках проекта оформлена тестовая документация и выделены основные зоны риска:

- связь корзины и авторизации;
- оформление заказа;
- зависимость Admin UI от PublicApi;
- обработка некорректных query-параметров;
- обработка ошибок;
- проверка пользовательского ввода;
- различия между Docker и local run окружениями.

## 6. Ограничения

- Исходный код eShopOnWeb не изменялся.
- Репозиторий содержит тестовые артефакты, а не fork продукта.
- Postman-коллекция является smoke-проверкой и не заменяет полноценные E2E-автотесты.
- Findings оформлены как тестовые находки, риски и сценарии для проверки, а не как набор доказанных production-багов.

## 7. Рекомендации

Для дальнейшего развития кейса можно добавить:

- Playwright E2E-тесты для сценариев Catalog → Basket → Checkout;
- API-тесты для PublicApi;
- негативные тесты на авторизацию;
- скриншоты/логи для каждого подтверждённого дефекта;
- раздел с test execution results после фактического прогона;
- GitHub Actions workflow с Newman, если приложение будет доступно в CI-среде.

## 8. Вывод

Проект демонстрирует умение разобрать внешний open-source продукт, определить зоны интеграционного риска, подготовить тестовую стратегию, составить чек-листы и оформить результаты тестирования в понятном для команды формате.

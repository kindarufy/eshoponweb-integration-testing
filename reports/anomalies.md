# Аномалии и ограничения наблюдений

## Окружение

Разные способы запуска eShopOnWeb используют разные адреса:

- Docker Compose: обычно `http://localhost:5106` для Web;
- локальный запуск через `dotnet run --launch-profile Web`: обычно `https://localhost:5001`.

Из-за этого Postman-тесты могут падать не из-за дефекта приложения, а из-за неправильного `webBaseUrl`.

## HTTPS

При локальном HTTPS-запуске возможны проблемы с доверенным сертификатом. В Postman это может потребовать дополнительной настройки SSL verification.

## Admin UI

Admin UI зависит от отдельного `PublicApi`. Если Web запущен без PublicApi, часть admin-сценариев может не работать. Это нужно рассматривать как особенность окружения, а не сразу как баг продукта.

## Big Bang testing

При Big Bang-подходе сложно быстро определить источник проблемы: один и тот же сбой может быть связан с UI, backend-логикой, авторизацией, базой данных или конфигурацией окружения.

# E2E-чек-лист eShopOnWeb

## Smoke

- [ ] Главная страница открывается.
- [ ] Страница логина открывается.
- [ ] Корзина открывается.
- [ ] Checkout без авторизации перенаправляет на login или обрабатывается ожидаемо.
- [ ] Admin URL открывается или корректно требует авторизацию.

## Каталог

- [ ] Отображаются карточки товаров.
- [ ] У товара отображается название.
- [ ] У товара отображается цена.
- [ ] У товара отображается изображение.
- [ ] Фильтр по бренду работает.
- [ ] Фильтр по типу товара работает.
- [ ] Пагинация работает.

## Корзина

- [ ] Товар добавляется в корзину.
- [ ] Количество товара отображается корректно.
- [ ] Итоговая сумма соответствует количеству и цене.
- [ ] Изменение количества пересчитывает итог.
- [ ] Удаление товара работает.
- [ ] Пустая корзина отображается корректно.

## Авторизация

- [ ] Demo-user может войти.
- [ ] Admin-user может войти.
- [ ] Некорректный пароль не даёт войти.
- [ ] Logout завершает сессию.

## Checkout

- [ ] Авторизованный пользователь может перейти к checkout.
- [ ] Checkout с пустой корзиной обрабатывается корректно.
- [ ] Checkout с товаром завершается подтверждением.
- [ ] Созданный заказ появляется в истории заказов.

## Admin

- [ ] Обычный пользователь не имеет доступа к admin-функциям.
- [ ] Admin-user открывает `/admin`.
- [ ] Список товаров в admin UI загружается.
- [ ] При недоступном PublicApi admin UI показывает понятное поведение.

## Security basics

- [ ] Ввод специальных символов не ломает страницу.
- [ ] HTML/JS-подобный ввод не выполняется как скрипт.
- [ ] Ошибки не показывают stack trace пользователю.
- [ ] Защищённые страницы требуют авторизацию.

# Стратегия тестирования

## Цель

Проверить, что основные части eShopOnWeb корректно работают вместе после интеграции в единое приложение.

## Выбранный подход

В учебном кейсе используется **Big Bang Integration Testing**.

При таком подходе компоненты рассматриваются как уже собранные в единую систему, а тестирование выполняется через пользовательские сценарии верхнего уровня.

## Почему этот подход выбран

Подход подходит для учебного анализа, потому что позволяет быстро проверить приложение как единую систему:

- Web UI;
- каталог товаров;
- корзину;
- Identity-аутентификацию;
- оформление заказа;
- историю заказов;
- Admin UI;
- Public API как зависимость admin-интерфейса.

## Ограничения подхода

Big Bang testing плохо локализует причины ошибок. Если сквозной сценарий падает, проблема может быть в UI, backend-логике, базе данных, конфигурации, сессии или внешнем сервисе.

Поэтому для промышленного тестирования лучше дополнить этот подход:

- модульными тестами;
- интеграционными тестами отдельных связок;
- API-тестами;
- контрактными тестами;
- E2E-автотестами через Playwright или Selenium;
- security-тестами пользовательского ввода и аутентификации.

## Уровни проверки

| Уровень | Что проверяется | Инструмент |
|---|---|---|
| Smoke | Доступность основных страниц | Postman |
| Manual E2E | Основные пользовательские сценарии | Browser checklist |
| Integration | Связки Catalog → Basket → Checkout → Identity | Manual / future automation |
| API/Admin dependency | Зависимость Admin UI от PublicApi | Manual / Postman extension |
| Security basics | Ввод, авторизация, ошибки, сессии | Security checklist |

## Критерии начала тестирования

- eShopOnWeb успешно запускается локально или через Docker;
- Web UI доступен в браузере;
- Postman environment настроен на правильный `webBaseUrl`;
- тестовые учётные данные доступны;
- база данных заполнена seed-данными.

## Критерии завершения тестирования

- пройдены smoke-проверки;
- выполнены основные E2E-сценарии;
- найденные проблемы занесены в реестр findings;
- ограничения тестирования описаны в отчёте;
- подготовлены рекомендации по дальнейшему тестированию.

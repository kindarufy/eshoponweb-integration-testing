# Базовый security-чек-лист

Этот чек-лист не является полноценным pentest-аудитом. Он фиксирует базовые проверки, которые полезно выполнить при интеграционном тестировании веб-приложения.

## Authentication / Authorization

- [ ] Страницы, требующие входа, недоступны анонимному пользователю.
- [ ] Admin UI недоступен обычному пользователю.
- [ ] После logout защищённые страницы требуют повторного входа.
- [ ] Сессия не даёт доступ к чужим заказам.

## Input Validation

- [ ] Поля формы логина валидируют email.
- [ ] Количество товара не принимает некорректные значения.
- [ ] Некорректные query-параметры не вызывают 500-ошибку.
- [ ] Пользовательский ввод не интерпретируется как HTML/JS.

## Error Handling

- [ ] Ошибки не раскрывают stack trace в production-like режиме.
- [ ] Некорректные URL обрабатываются ожидаемо.
- [ ] Ошибки авторизации отделены от ошибок сервера.

## Session / Basket

- [ ] Корзина сохраняется в ожидаемых сценариях.
- [ ] Корзина не смешивается между разными пользователями.
- [ ] Logout не оставляет доступ к данным пользователя.

## Admin / PublicApi

- [ ] Admin UI корректно работает только при доступном PublicApi.
- [ ] PublicApi не раскрывает административные данные без авторизации.
- [ ] Ошибки PublicApi не ломают весь Web UI без понятного сообщения.

# Тест-кейсы

## TC-001. Открытие главной страницы

**Предусловия:** eShopOnWeb запущен.  
**Шаги:**
1. Открыть `webBaseUrl` в браузере.
2. Проверить, что страница загрузилась.
3. Проверить, что каталог/баннер отображаются.

**Ожидаемый результат:** главная страница открывается без 5xx-ошибок и видимых ошибок интерфейса.

## TC-002. Просмотр каталога

**Шаги:**
1. Открыть главную страницу.
2. Проверить наличие карточек товаров.
3. Проверить отображение названий, цен и изображений.

**Ожидаемый результат:** каталог отображает seed-товары корректно.

## TC-003. Фильтрация каталога

**Шаги:**
1. Выбрать фильтр бренда или типа товара.
2. Применить фильтр.
3. Проверить, что список товаров изменился.

**Ожидаемый результат:** отображаются товары, соответствующие выбранному фильтру.

## TC-004. Пагинация каталога

**Шаги:**
1. Открыть каталог.
2. Перейти на следующую страницу каталога.
3. Вернуться на предыдущую страницу.

**Ожидаемый результат:** пагинация работает без ошибок, состояние фильтров не ломается.

## TC-005. Добавление товара в корзину

**Шаги:**
1. На главной странице выбрать товар.
2. Нажать кнопку добавления в корзину.
3. Перейти в корзину.

**Ожидаемый результат:** выбранный товар отображается в корзине с корректной ценой и количеством.

## TC-006. Изменение корзины

**Шаги:**
1. Открыть корзину с добавленным товаром.
2. Изменить количество товара.
3. Обновить корзину.
4. Удалить товар из корзины.

**Ожидаемый результат:** итоговая сумма пересчитывается корректно, удаление товара работает ожидаемо.

## TC-007. Авторизация demo-user

**Шаги:**
1. Открыть страницу входа.
2. Ввести `demouser@microsoft.com`.
3. Ввести пароль `Pass@word1`.
4. Нажать Log in.

**Ожидаемый результат:** пользователь успешно авторизован.

## TC-008. Checkout с заполненной корзиной

**Предусловия:** пользователь авторизован, корзина содержит товар.  
**Шаги:**
1. Перейти в корзину.
2. Нажать Checkout.
3. Подтвердить оформление заказа.
4. Проверить страницу результата.

**Ожидаемый результат:** заказ оформляется без 5xx-ошибок, пользователь видит подтверждение.

## TC-009. Просмотр истории заказов

**Предусловия:** пользователь авторизован и имеет хотя бы один заказ.  
**Шаги:**
1. Перейти в раздел заказов.
2. Открыть список заказов.
3. Проверить данные последнего заказа.

**Ожидаемый результат:** история заказов отображается корректно.

## TC-010. Проверка Admin UI

**Предусловия:** Web и PublicApi запущены, пользователь admin доступен.  
**Шаги:**
1. Войти как `admin@microsoft.com`.
2. Открыть `/admin`.
3. Проверить загрузку списка товаров.

**Ожидаемый результат:** admin-интерфейс загружается и получает данные через PublicApi.

## TC-011. Проверка ошибок и некорректных URL

**Шаги:**
1. Открыть несуществующий URL.
2. Открыть страницу, требующую авторизации, без входа.
3. Проверить поведение приложения.

**Ожидаемый результат:** приложение показывает корректные страницы ошибки или перенаправляет на login, не раскрывая технические детали.

## TC-012. Базовая проверка security-вводов

**Шаги:**
1. В поля ввода ввести специальные символы и HTML-подобные строки.
2. Проверить, что ввод не выполняется как HTML/JS.
3. Проверить сообщения об ошибках.

**Ожидаемый результат:** пользовательский ввод экранируется или валидируется, технические детали не раскрываются.
